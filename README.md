# T008 · Protein data acquisition: Protein Data Bank (PDB)

Implementation of the TeachOpenCADD talktorial
[T008 · Query the PDB](https://projects.volkamerlab.org/teachopencadd/talktorials/T008_query_pdb.html).

The notebook queries the PDB for EGFR (UniProt `P00533`) structures, filters them by
deposition date, experimental method, resolution, chain count and ligand size, sorts the
hits by resolution, pulls the ligand metadata for the four orthosteric complexes
(5UG9, 5HG8, 5UG8, 5UGC), superposes the complexes and writes the extracted ligands to
`data/` for the next talktorial.

## Contents

- `talktorial.ipynb` — the talktorial, executed end to end
- `images/protein-ligand-complex.png` — figure used in the theory section
- `requirements.txt` — dependencies
- `WALKTHROUGH.md` — notes on how the talktorial was put together, including the environment and API issues it works around
- `data/` — structures, ligand files and `PDB_top_ligands.csv`, generated by running the notebook

## Setup and run

```bash
pip install -r requirements.txt
jupyter lab talktorial.ipynb
```

## Notes

- The 3D superposition uses `MDAnalysis` directly. The original talktorial uses the
  `opencadd` package, which does not build on current Python versions; `MDAnalysis` is the
  engine behind `opencadd`'s superposition module. Because the crystallized constructs
  differ in length, the superpositions are computed on the Cα atoms of the residues shared
  by all structures.
- The `nglview` cells only render in a live Jupyter frontend; they do not produce output
  when the notebook is executed headlessly.
- Run with Python 3.14: on the default 3.15 interpreter here, `biotite`'s `biotraj` dependency cannot build (no MSVC build tools, no wheel).
